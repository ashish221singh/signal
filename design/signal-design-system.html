01

Brand

A square that is the letter — the S runs edge to edge, and the two notches are the only negative space. One mark, everywhere: favicon, app icon, nav, splash.

Usage
  • Wordmark: Schibsted Grotesk Bold, lowercase, −0.028em tracking, gap = 33% of mark height.
  • Clear space around the mark = one notch height (25% of mark) on all sides.
  • Minimum size 16px. Mark colors: orange on light, white on dark, ink in monochrome.
  • Never recolor the mark outside orange, white, or ink. Never add shadows, outlines, or gradients.
  • Never rotate, skew, or place on busy imagery without a scrim.
  • Never redraw, fragment, or decompose the mark — it ships as one shape, always whole.
02

Color

60% white, 30% warm gray, 10% color. Orange acts — it owns every primary action and brand moment. Blue informs — data, links, focus. They never compete on the same element. Click any swatch to copy.

Orange acts

Primary buttons, selected states, the current period in charts, brand marks. Labels on orange are white, 600 weight, 14px+ — and only ever button labels, never body copy.

Blue informs

Charts, links, focus rings, info states. As text on white, use blue-700 or darker. Blue never appears on a primary action — that's orange's job.

Ink speaks

Warm-tinted grays carry all text and structure. Body is gray-900 on white (16:1). Secondary gray-600. Never pure black, never cool gray.

05

Motion

Motion answers three questions: did it register, where did it come from, what changed. If it answers none — it doesn't animate. Everything under 300ms except the sheet and brand moments. Transform, opacity, and filter only.

Enter recipe
opacity + 10px rise + blur(5) · 480ms ease-out
Press
scale(0.96) on :active · 90ms
Icon swap
opacity + scale(.8) + blur(3) · 140ms
Easing
ease-out · ease-inout · linear (never bare "ease")
Laws
  • Exits are subtler than enters — smaller travel, faster, the user has moved on.
  • High-frequency actions (row clicks, keyboard shortcuts) never animate.
  • Dropdowns and popovers grow from their trigger — transform-origin matters.
  • The bottom sheet uses the iOS-native curve: cubic-bezier(0.32, 0.72, 0, 1) · 480ms.
  • One expressive moment per surface — the logo assembly, a check drawing. Never two.
  • prefers-reduced-motion collapses every animation to instant. Shipped in tokens.css, non-negotiable.

The Sheet

The product itself — the SDK bottom sheet, fully working. Rate 4–5 stars for the positive branch, 1–3 for chips and the "Other" text path. One expressive moment (the check draws itself); everything else is quick and quiet.

Why it feels right
  • Enters with the iOS-native sheet curve — 480ms, cubic-bezier(0.32, 0.72, 0, 1) — because reps' hands know that physics.
  • State changes use blur-as-bridge: the old state blurs out 150ms, the new rises in 260ms. No layout jumps register.
  • The selected star pops 1.25× for 260ms — the single tactile confirmation of the entire interaction.
  • The check draws itself once, at the end. Peak-end rule: the last thing a rep sees is their feedback being received.
  • Skip is always one tap, top-right, never guilt-tripped. Suppression rules handle the rest server-side.
  • Play Store prompt appears only on the positive branch, only when the campaign config asks for it.

09

Rules

The judgment calls, written down — so a new engineer, a new designer, or an agent building a screen makes the same call we would.

DO

One orange action per view

If two things are orange, neither is primary. Everything else is secondary, ghost, or a link.

DON'T

No reading text on orange

Orange carries white button labels only — bold, 14px+. Body copy never sits on orange, and orange text on white must be orange-700 or darker.

DO

Shadows carry structure

Cards, inputs, and menus separate with layered shadows, not borders. Hairline borders only for table rows and section dividers.

DON'T

No decorative motion

No pulsing dots, breathing CTAs, or looping attention-seekers. If motion doesn't confirm, orient, or connect — cut it.

DO

Design for one thumb on 4G

44px minimum targets, one decision per screen, optimistic UI on submit. The rep is standing in a shop.

DON'T

Never block on feedback

Skip is always visible, dismissal is one gesture, and the sheet never re-asks within its cooldown. Trust is the product.
